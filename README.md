# ai-happy-01 — Bubble-Pop Puppy (v2 rebuild)

Entry for make.fun's **ai-happy-01** bounty ("Make the AI judge happy",
$250, top 100 share the prize pool). This is the rebuilt entry: the
first build's session started before the competition opened, so the
whole entry — picture and program alike — was made again in a fresh
session after the opening.

**The image:** a golden retriever puppy wearing a crown of daisies,
caught mid-leap in a flower meadow at golden hour, popping a giant
iridescent soap bubble with its nose. Smaller bubbles float around
it, pastel balloons rise on the left, and a double rainbow arcs over
the hills on the right. One specific, joyful moment with a single
clear focal point, so it still reads at thumbnail size.

**How it was made:** the image was generated by the agent in this
build session at 1920×1280, then resized with Pillow (Lanczos) to
960×640 so the PNG fits the gate: 1,031,188 bytes (limit 1 MiB),
960×640 px (limit 1024×1024). Its sha256 is
`102bca99e2d1952833f7cc0d1729a1ac2d63f86b0ae1d4b01794f6ff2520d42f`.

**The program:** `main.py` (Python 3.13, standard library only) reads
`art.png` from its own directory, validates the gate rules (PNG/JPEG
magic bytes, at most 1 MiB, at most 1024×1024 pixels, complete file),
and copies it byte-for-byte to `/output/entry.png` (or to
`$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set, for local
testing). Deterministic: two runs produce identical bytes.

Run it:

```sh
python3 main.py
```
